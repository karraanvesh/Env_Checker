**Steps to setup the project**

1. Clone the project

`git clone https://github.com/karraanvesh/Env_Checker.git <ProjectName>`

2. Move in to the folder structure 

`cd <ProjectName>`

3. Install npm dependencies

`npm install`

4. Create a new .env file in the root directory and add the required env variables

`PATH , API_KEY , DATABASE_URL etc`

5. Run the index.js

`node index.js <Any Environment variables you want to pass>`
